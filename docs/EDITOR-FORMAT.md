# 编辑器首行缩进

在「偏好设置 → 编辑器排版 → 首行缩进」中选择段落的显示方式：

- **不缩进**：默认选项，保持原有排版。
- **2 字符**：正文段落首行缩进 `2em`，即当前正文字号的两倍。

设置立即应用于文档正文段落的首行，后续行仍保持原来的位置。
它不影响标题、列表、引用、代码、表格或聊天内容，也不会向 Markdown 中插入空格或修改文档内容。

选择会保存在现有用户偏好中，重启 Flowix 后仍然保留。
点击「恢复默认」会将首行缩进恢复为「不缩进」，同时重置其他编辑器排版选项。

升级后继续使用此设置，需要目标版本也包含首行缩进功能。
尚未包含该功能的官方版本不会应用此排版效果。
