# 编辑器首行缩进

在「偏好设置 → 编辑器排版 → 首行缩进」中选择段落的显示方式：

- **无**：默认选项，保持原有排版。
- **2 EM**：正文段落首行缩进 `2em`，即当前正文字号的两倍。中英文界面均显示为「2 EM」。

设置立即应用于文档正文段落的首行，后续行仍保持原来的位置。
它不影响标题、列表、引用、代码、表格或聊天内容，也不会向 Markdown 中插入空格或修改文档内容。

选择会保存在现有用户偏好中，重启 Flowix 后仍然保留。
点击「恢复默认」会将首行缩进恢复为「无」，同时重置其他编辑器排版选项。

这是所有笔记共用的显示偏好，只作用于顶层正文段落。按 Enter 新建段落会继续首行缩进，按 Shift+Enter 在同一段落内换行则不会再次缩进。
缩进不作为空格写入正文，因此不能用 Backspace 单独删除。正文已有的空格会保留，并与显示缩进叠加。
通过编辑器打印生成的 PDF 会保留当前缩进；Markdown 内容保持不变。

升级后继续使用此设置，需要目标版本也包含首行缩进功能。
尚未包含该功能的官方版本不会应用此排版效果。

开发验证可运行 `npm run check:editor-indent-layout`，使用 Chromium 实际测量空段落、换行、字号变化和光标位置。可通过 `CHROME_BIN` 指定浏览器路径。
